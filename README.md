# OSCP Study Notes

Personal notes from my journey studying for the OSCP (Offensive Security Certified Professional). Sharing these publicly to track my own progress and hopefully help others starting out too.

> **Disclaimer:** These notes are for educational purposes only, based on general penetration testing methodology and publicly available techniques/tools. They do not contain any OffSec exam content, PWK/PEN-200 course material, or specific exam walkthroughs, in line with OffSec's certification policies. All practice was done in legal, authorized lab environments (e.g., HackTheBox, TryHackMe, OffSec's own labs).
