## 📖 About This Repo

This repository contains my personal notes, cheat sheets, and reference material covering the full OSCP (PEN-200) syllabus — written as I study, not after the fact. Everything here reflects my own understanding, so corrections and PRs are genuinely welcome.

**What you'll find:**
- Topic-by-topic notes following the official PEN-200 methodology
- Standalone tool cheat sheets for quick reference during labs/exam
- Supporting cybersecurity fundamentals (frameworks, methodology, career context)
